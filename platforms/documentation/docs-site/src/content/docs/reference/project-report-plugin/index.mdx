The Project report plugin adds some tasks to your project which generate reports containing useful information about your build. These tasks generate the same content that you get by executing the `tasks`, `dependencies`, and `properties` tasks from the command line (see <Xref page="command-line-interface" section="Project reporting">Command-line project reporting</Xref>). In contrast to the command line reports, the report plugin generates the reports into a file. There is also an aggregating task that depends on all report tasks added by the plugin.

We plan to add much more to the existing reports and create additional ones in future releases of Gradle.

## Usage

To use the Project report plugin, include the following in your build script:

```groovy
plugins {
    id 'project-report'
}
```

## Tasks

The project report plugin defines the following tasks:

<dl>
<dt>`dependencyReport` — <GroovyDocLink class="org.gradle.api.tasks.diagnostics.DependencyReportTask" /></dt>
<dd>

Generates the project dependency report.

</dd>
<dt>`htmlDependencyReport` — <GroovyDocLink class="org.gradle.api.reporting.dependencies.HtmlDependencyReportTask" /></dt>
<dd>

Generates an HTML dependency and dependency insight report for the project or a set of projects.

</dd>
<dt>`propertyReport` — <GroovyDocLink class="org.gradle.api.tasks.diagnostics.PropertyReportTask" /></dt>
<dd>

Generates the project property report.

</dd>
<dt>`taskReport` — <GroovyDocLink class="org.gradle.api.tasks.diagnostics.TaskReportTask" /></dt>
<dd>

Generates the project task report.

</dd>
<dt>`projectReport` — <GroovyDocLink class="org.gradle.api.Task" /></dt>
<dd>

_Depends on_: `dependencyReport`, `propertyReport`, `taskReport`, `htmlDependencyReport`

Generates all project reports.

</dd>
</dl>

## Project layout

The project report plugin does not require any particular project layout.

## Dependency management

The project report plugin does not define any dependency configurations.
