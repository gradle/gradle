The ANTLR plugin extends the Java plugin to add support for generating parsers using [ANTLR](http://www.antlr.org/).

:::note
The ANTLR plugin supports ANTLR version 2, 3 and 4.
:::

## Tasks

The ANTLR plugin adds a number of tasks to your project, as shown below.

<dl>
<dt>`generateGrammarSource` — <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrTask" /></dt>
<dd>

Generates the source files for all production ANTLR grammars.

</dd>
<dt>`generateTestGrammarSource` — <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrTask" /></dt>
<dd>

Generates the source files for all test ANTLR grammars.

</dd>
<dt>`generate_SourceSet_GrammarSource` — <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrTask" /></dt>
<dd>

Generates the source files for all ANTLR grammars for the given source set.

</dd>
</dl>

The ANTLR plugin adds the following dependencies to tasks added by the Java plugin.

**ANTLR plugin - additional task dependencies**

| Task name | Depends on |
| --- | --- |
| `compileJava` | `generateGrammarSource` |
| `compileTestJava` | `generateTestGrammarSource` |
| `compile_SourceSet_Java` | `generate_SourceSet_GrammarSource` |

## Project layout

<dl>
<dt>`src/main/antlr`</dt>
<dd>

Production ANTLR grammar files. If the ANTLR grammar is organized in packages, the structure in the antlr folder should reflect the package structure. This ensures that the generated sources end up in the correct target subfolder.

</dd>
<dt>`src/test/antlr`</dt>
<dd>

Test ANTLR grammar files.

</dd>
<dt>`src/_sourceSet_/antlr`</dt>
<dd>

ANTLR grammar files for the given source set.

</dd>
</dl>

## Contributed extension

<dl>
<dt>`antlr` — <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrSourceDirectorySet" /></dt>
<dd>

The ANTLR grammar files of this source set. Contains all `.g` or `.g4` files found in the ANTLR source directories, and excludes all other types of files. _Default value is non-null._

</dd>
</dl>

## Convention properties (deprecated)

The ANTLR plugin adds one convention property.

<dl>
<dt>`antlr` — <GroovyDocLink class="org.gradle.api.file.SourceDirectorySet" /></dt>
<dd>

The ANTLR grammar files of this source set. Contains all `.g` or `.g4` files found in the ANTLR source directories, and excludes all other types of files. _Default value is non-null._

</dd>
</dl>

This convention property is **deprecated** and superseded by the extension described above.

## Source set properties

The ANTLR plugin adds the following properties to each source set in the project.

<dl>
<dt>`antlr.srcDirs` — `Set<File>`</dt>
<dd>

The source directories containing the ANTLR grammar files of this source set.
Can set using anything <Xref page="working-with-files" section="Understanding implicit conversion to file collections">that implicitly converts to a file collection</Xref>.
Default value is `[_projectDir_/src/_name_/antlr]`.

</dd>
</dl>

## Controlling the ANTLR generator process

The ANTLR tool is executed in a forked process. This allows fine grained control over memory settings for the ANTLR process. To set the heap size of an ANTLR process, the `maxHeapSize` property of <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrTask" /> can be used. To pass additional command-line arguments, append to the `arguments` property of <GroovyDocLink class="org.gradle.api.plugins.antlr.AntlrTask" />.
