The CodeNarc plugin performs quality checks on your project’s Groovy source files using [CodeNarc](https://codenarc.org/) and generates reports from these checks.

## Usage

To use the CodeNarc plugin, include the following in your build script:

<SampleScripts sample_name="code-quality" basename="build" tag="use-codenarc-plugin" source_dir="snippets/reference/core-plugins/codeQuality" />

The plugin adds a number of tasks to the project that perform the quality checks when used with the <Xref page="groovy-plugin" section="The Groovy Plugin">Groovy Plugin</Xref>. You can execute the checks by running `gradle check`.

## Tasks

The CodeNarc plugin adds the following tasks to the project:

<dl>
<dt>`codenarcMain` — <GroovyDocLink class="org.gradle.api.plugins.quality.CodeNarc" /></dt>
<dd>

Runs CodeNarc against the production Groovy source files.

</dd>
<dt>`codenarcTest` — <GroovyDocLink class="org.gradle.api.plugins.quality.CodeNarc" /></dt>
<dd>

Runs CodeNarc against the test Groovy source files.

</dd>
<dt>`codenarc_SourceSet_` — <GroovyDocLink class="org.gradle.api.plugins.quality.CodeNarc" /></dt>
<dd>

Runs CodeNarc against the given source set’s Groovy source files.

</dd>
</dl>

### Dependencies added to other tasks

The CodeNarc plugin adds the following dependencies to tasks defined by the Groovy plugin.

<dl>
<dt>`check`</dt>
<dd>

_Depends on_: All CodeNarc tasks, including `codenarcMain` and `codenarcTest`.

</dd>
</dl>

## Project layout

The CodeNarc plugin expects the following project layout:

```text callouts
<root>
└── config
    └── codenarc           // (1)
        └── codenarc.xml   // (2)
```

<CalloutList>

1. CodeNarc configuration files go here
2. Primary CodeNarc configuration file

</CalloutList>

:::note
The default configuration file is resolved relative to the _root_ project directory, so a single `config/codenarc/codenarc.xml` is shared by all projects in the build unless the `config` property is overridden.
:::

## Configuration

The CodeNarc plugin is configured through the <GroovyDocLink class="org.gradle.api.plugins.quality.CodeNarcExtension" /> (the `codenarc {}` block). The most commonly used properties and their default values are:

**Gradle defaults for CodeNarc properties**

| Property | Description | Gradle default |
| --- | --- | --- |
| `toolVersion` | The version of CodeNarc to use. | `3.7.0-groovy-4.0` |
| `config` | The CodeNarc configuration to use. | `config/codenarc/codenarc.xml` (relative to the root project) |
| `reportFormat` | The format of the generated report. One of `html`, `xml`, `text`, or `console`. | `html` |
| `maxPriority1Violations` | The maximum number of priority 1 violations allowed before failing the build. | `0` |
| `maxPriority2Violations` | The maximum number of priority 2 violations allowed before failing the build. | `0` |
| `maxPriority3Violations` | The maximum number of priority 3 violations allowed before failing the build. | `0` |
| `reportsDirectory` | The directory where reports are generated. | `layout.buildDirectory.dir("reports/codenarc")` |

See the <GroovyDocLink class="org.gradle.api.plugins.quality.CodeNarcExtension" /> class in the API documentation for the full set of options.
